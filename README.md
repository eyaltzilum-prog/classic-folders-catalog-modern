# Classic Folders Catalog – Modern Redesign

Modern, attractive, and scalable redesign of the end-of-year certificate folders catalog (תעודות מחזור).

- **Original repo (backup):** [catalog-end-of-the-year-folders](https://github.com/eyaltzilum-prog/catalog-end-of-the-year-folders)
- **This repo:** New UI while keeping all products and images identical.

## Features
- Responsive product grid (mobile → desktop)
- Search by name / code / description
- Lightbox with image gallery
- RTL Hebrew support
- Sticky header with phone & WhatsApp CTAs
- Clean modern design with Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```

Built with React 19 + Vite + Tailwind.
